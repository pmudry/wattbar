Watts, not CPU load.

WattBar puts your laptop's real battery drain in the tray, in watts, with a chart, the instantaneous CPU package power, and a view of which process is actually draining it.

Showcase

The flyout

The battery gauge in magenta is the truth over minutes: a slow rolling value with the whole machine in it. The package line in blue reacts within a second, so it tells you whether a change you just made did anything.

Averages come from the drop in remaining capacity, not from the mean of gauge samples. Standby shows as a gap, not a line.

Who is using the battery

Every minute Windows estimates how much energy each process caused. WattBar merges those estimates per process, adds the process state, spreads the measured package power across them, and highlights the background process that stays near the top.

Windows only lets administrators read that trace, so the window says why, and lets you choose a prompt each time, a scheduled task installed once, or nothing at all.

In the tray, out of the way

The digits keep one size and one decimal below 10 W. Behind them, a sparkline of the last two minutes. Click once for the chart, click again to close it. The gear opens theme, language, power mode, package readout rate and start with Windows.

Why

CPU load is not battery drain. Task Manager will happily show 2 % CPU while the laptop empties in three hours, because most of what costs energy never shows up as CPU time: the display backlight, a power scheme silently switched to High performance, a process holding the system timer at 1 ms so the CPU package can never go to deep idle, the GPU compositing a large high-refresh screen, Wi-Fi and SSD kept awake by a plan setting.

This tool came out of exactly that hunt: an idle drain of 9 to 15 W on a ThinkPad that ended at 2 to 3 W, with none of the culprits visible in the usual places.

So WattBar shows watts, the unit the battery actually cares about, from two angles. The battery gauge is the truth over minutes. The CPU package power is instantaneous. The gap between the two is the display and the rest of the machine.

And because "which process" is the next question, the per-process view surfaces Windows' own energy accounting, ranked so that a heavy process running in the background stands out. The measurements behind these choices are written up in the findings document.

Install

Windows 10 build 19041 or later, x64. No installer: the exe is the app.

  1. Get the runtime, once. WattBar needs the .NET Desktop Runtime 10 or newer. If it is missing, Windows offers the download when you start the exe, or run:
    winget install Microsoft.DotNet.DesktopRuntime.10
  2. Download WattBar.exe and put it anywhere you like. Run it. It lives in the tray and promotes itself out of the overflow area.

    Tick Start with Windows in the menu if you want it back after a reboot.

  3. Optional: the per-process view. Open Who is using it from the menu. Choose a UAC prompt each time, a scheduled task registered once with consent and started silently afterwards, or leave the feature off. Nothing else in WattBar needs administrator rights.

FAQ

Why does the tray number change only every 30 to 60 seconds?

That is the battery gauge itself: the fuel-gauge chip reports a one-minute rolling average and refreshes it every 30 to 60 s. WattBar shows it raw rather than smoothing it further. The CPU package figure in the flyout is the one that reacts instantly.

What does it show when I'm plugged in?

With an idle battery there is no drain to report, so the tray and the flyout headline switch to the CPU package power, drawn in blue so the two are never confused.

Are the per-process numbers watts?

No. They are shares of Windows' own energy estimates, whose unit is undocumented. The ≈ CPU W column spreads the measured package power across processes by their CPU share, which is an estimate. Screen energy always goes to the window in front, so rank by CPU share to find the real offender.

Where are the settings stored?

Under HKCU\Software\WattBar. The collector writes its summaries to %ProgramData%\WattBar. Delete both and the exe, and WattBar is gone.

Does it phone home?

No. There is no network code in it. The download link on this page points at the GitHub release.
